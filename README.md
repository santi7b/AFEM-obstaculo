# AFEM-obstaculo
AFEM para el problema del obstáculo con elementos de Crouzeix–Raviart

Implementación en Python del método de elementos finitos adaptativos de
Bartels y Kaltenbach para el problema del obstáculo: elementos de
Crouzeix–Raviart, Newton semisuave, reconstrucción de flujo de Marini
y estimador de brecha primal-dual.

Parte del código se elaboró con asistencia de Claude (Anthropic).

## Uso
python implementacion_obstaculo.py

Requiere numpy, scipy y matplotlib.

## Referencia
S. Bartels, A. Kaltenbach. Error analysis for a Crouzeix-Raviart
approximation of the obstacle problem. J. Numer. Math., 34(3):271–305, 2026.
